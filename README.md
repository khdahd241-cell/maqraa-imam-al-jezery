# مقرأة الإمام الجزري

موقع تعريفي أولي لمقرأة الإمام الجزري للقراءة والإجازة بالسند المتصل.

## الصفحات
- الرئيسية
- الدورات
- التسجيل
- عن المقرأة
- تواصل معنا

## التشغيل على Render
هذا المشروع مجهز ليعمل كـ Web Service:
- Build Command: `npm install`
- Start Command: `npm start`

> هذه النسخة واجهة أولية. نموذج التسجيل حاليًا تجريبي، وسيتم في المرحلة التالية ربطه بقاعدة بيانات وواتساب/بريد إلكتروني ولوحة تحكم.
